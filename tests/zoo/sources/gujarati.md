# પરિચય

આ માર્ગદર્શિકા ઇલેક્ટ્રિક વાહન ચાર્જરના ઉપયોગ વિશે છે. ચાર્જર દિવસ અને રાત બંને સમયે કામ કરે છે. તેને ફક્ત તાલીમ પામેલા વ્યક્તિએ જ સ્થાપિત કરવું જોઈએ.

# સલામતી

ચાર્જર ખોલતા પહેલાં વીજળી બંધ કરો. ભીના હાથે કેબલને સ્પર્શ કરશો નહીં. જો કેબલ તૂટેલો હોય તો ચાર્જિંગ શરૂ કરશો નહીં.

# ઉપયોગ

1. વાહનમાં કેબલ લગાવો.
2. સ્ક્રીન પર શરૂ બટન દબાવો.
3. ચાર્જિંગ પૂરું થાય ત્યારે કેબલ કાઢી લો.
