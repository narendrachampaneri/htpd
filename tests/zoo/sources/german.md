# Einführung

Dieses Handbuch beschreibt die Ladestation für Elektrofahrzeuge. Die Ladestation darf nur von geschultem Fachpersonal installiert werden. Für Schäden durch unsachgemäße Installation übernehmen wir keine Haftung.

# Sicherheitshinweise

Schalten Sie vor dem Öffnen des Gehäuses die Stromversorgung ab. Berühren Sie das Kabel nicht mit nassen Händen. Verwenden Sie die Ladestation nicht, wenn das Kabel beschädigt ist.
